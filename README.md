## 1. Постановка задачи

Цель лабораторной работы — разработать программный проект для обработки данных о студентах, вычисления их рейтингов и анализа результатов. Проект должен быть структурирован, покрыт модульными тестами и интегрирован с системой непрерывной интеграции GitHub Actions.

Задачи работы:

1. Познакомиться с распределённой системой контроля версий кода Git и её функциями.
2. Познакомиться с понятиями «непрерывная интеграция» (CI) и «непрерывное развертывание» (CD), определить их место в современной разработке программного обеспечения.
3. Получить навыки разработки ООП‑программ и написания модульных тестов к ним на современных языках программирования.
4. Получить навыки работы с системой Git для хранения и управления версиями программного обеспечения.
5. Получить навыки управления автоматизированным тестированием программного обеспечения, расположенного в системе Git, с помощью инструмента GitHub Actions.
6. Выбрать тип лицензии для проекта и добавить файл LICENSE в репозиторий.
7. Добавить файл .gitignore и сформировать его содержимое для исключения временных, служебных и автоматически генерируемых файлов.
8. Реализовать программу, рассчитывающую средний рейтинг студентов по дисциплинам.
9. В рамках индивидуального задания — определить и вывести всех студентов, чей рейтинг попадает в последнюю квартиль распределения по рейтингам (данные предоставляются в JSON‑файле).
10. Составить UML‑диаграмму классов проекта.
11. Подготовить README.md, включающий описание проекта, постановку задачи, используемые технологии, UML‑диаграмму и выводы по работе.

## 2. Краткое описание проекта

Проект представляет собой программу, которая:

- считывает данные о студентах из текстового или JSON‑файла;
- вычисляет средний рейтинг каждого студента;
- определяет студентов, чей рейтинг попадает в последнюю квартиль распределения;
- выводит результаты в консоль.

Программа реализована с использованием объектно‑ориентированного подхода и разделена на логические компоненты:

- `DataReader` — абстрактный класс для чтения данных;
- `JsonDataReader` — чтение данных из JSON‑файла;
- `TextDataReader` — чтение данных из текстового файла;
- `CalcRating` — вычисление среднего рейтинга студентов;
- `RatingAnalyzer` — анализ рейтингов и определение последнего квартиля;
- `main.py` — точка входа, связывающая все компоненты.
